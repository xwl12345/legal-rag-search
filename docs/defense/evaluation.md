# 检索质量量化评测报告

> 评测对象：legal-rag-search 混合检索器（BM25 路径，无 API Key 降级模式）
> 语料：21 篇模拟裁判文书（118 文本块）——8 民事 / 5 刑事 / 3 行政 / 3 知识产权 / 2 商事
> 查询集：23 条人工标注查询（案情描述型 10 / 法律术语型 7 / 易混区分型 3 / 多相关文档型 1 / 组合 2）
> 评测程序：`test/eval_retrieval.cpp`（`build/eval_retrieval.exe`，从项目根目录运行）
> 原始输出：[eval_results.txt](eval_results.txt)

## 一、总体结果

| 指标 | 数值 | 说明 |
|---|---|---|
| **Hit@5（命中率）** | **0.957**（22/23） | Top-5 文档中至少命中一个相关文档的查询占比 |
| **Recall@10** | **0.957** | Top-10 内找到的相关文档占全部相关文档的比例 |
| **MRR（平均倒数排名）** | **0.913** | 首个相关文档排名位置的倒数均值，越大越靠前 |
| P@5 | 0.200 | 本查询集以单相关文档为主，该指标理论上限即 1/5 = 0.2；22/23 条查询达到上限 |

**结论：23 条查询中 22 条将相关文书排进 Top-5，其中 21 条排名第 1；唯一失败案例具有明确成因（见第三节）。**

## 二、查询集设计

| 类型 | 数量 | 示例 | 考察点 |
|---|---|---|---|
| A 案情描述型 | 11 | 「夫妻感情破裂离婚孩子抚养权归属」「醉驾血液酒精含量 危险驾驶罪」 | 自然语言案情 → 文书的语义匹配 |
| B 法律术语型 | 7 | 「民间借贷纠纷」「盗窃罪立案量刑标准」 | 案由/罪名术语直接匹配 |
| C 易混区分型 | 3 | 「财务人员侵占公司资金」（应命中职务侵占而非损害公司利益）、「商标无效宣告行政诉讼」（应命中行政案而非民事知产案） | 相近案由的判别力 |
| D 多相关文档型 | 1 | 「商标权纠纷」（同时命中民事商标侵权 + 商标行政无效宣告） | 多相关文档召回 |
| 组合 | 1 | 「借钱不还被起诉会有什么后果」（口语化改写，排名第 2） | 口语→法律用语映射 |

标注依据：各文书的案由字段与案情事实（如「财务人员侵占公司资金」对应刑事卷中职务侵占罪一案，而非商事卷中股东诉法定代表人损害公司利益一案——后者无"侵占"行为，构成有效区分样本）。

## 三、失败案例分析：中文词汇失配（Vocabulary Mismatch)

**失败查询**：「电信诈骗数额较大怎么判刑」→ 期望命中 `case_criminal_001_fraud.txt`（诈骗罪判决书），实际未命中（Top-50 均无）。

**根因分析**（jieba 分词层面逐词核对）：

| 查询词（jieba 切分结果） | 文书中的表述 | 是否匹配 |
|---|---|---|
| 电信 | 「通过**互联网**发布虚假的投资理财信息」 | ✗ 文书无「电信」 |
| 诈骗 | 通篇为「**诈骗罪**」（jieba 词典整词） | ✗ 词面不同 |
| 数额较大 | 「数额**特别巨大**」；且 jieba 词典将「数额较大」收录为整词（freq=3） | ✗ |
| 判刑 | 「判处**有期徒刑十年**」 | ✗ 文书用规范量刑表述 |

四组词面全部错开，BM25（精确词项匹配）得分为零。**这是中文信息检索经典的词汇失配问题**：文书使用规范法律用语（诈骗罪/数额特别巨大/有期徒刑），用户提问使用口语（诈骗/数额较大/判刑）。

**这正是本系统设计向量语义检索支路的动机**——embedding 可将「诈骗」与「诈骗罪」映射到邻近语义空间。当前部署环境未接入可用 embedding 服务（DeepSeek 不提供 embeddings 端点，系统按设计降级为纯 BM25），故该案例在本次评测中暴露。改进路径：接入 OpenAI 兼容 embedding 服务、或增加轻量级同义词/词干归一化层（诈骗→诈骗罪）。

## 四、其他观察

- **易混区分型 3/3 全部正确**：职务侵占 ≠ 损害公司利益、商标行政无效 ≠ 商标民事侵权、业主受伤（生命权健康权）能从 21 篇中精准区分，说明法律自定义词典 + 案由词的 BM25 判别力良好。
- **口语化改写**（「借钱不还被起诉会有什么后果」）排名第 2（MRR 贡献 0.5），归功于文书中的口语化诉称表述（「借款」「还款」等词重叠）。
- **多相关文档查询**（「商标权纠纷」）Top-1 即命中，两份相关文书均进入 Top-5（R@10=1.0）。
